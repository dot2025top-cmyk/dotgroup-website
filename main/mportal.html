Five-to-Six-Person Community Approval Process — Default rule set by DOTGROUP during activation — Community must not be able to lower own threshold for particular withdrawal

Withdrawal Workflow
1. Authorized person submits request — Amount, currency, purpose, recipient, supporting evidence — 2. System checks available balance + spending limits — 3. Records as Pending Approval — 4. Notifies registered phone + authorized representatives — 5. Each required representative reviews + submits individual approvals/objections via authenticated accounts — 6. Verifies required number distinct authorized representatives approved — 7. Checks unresolved objections, active freezes, suspected fraud, conflicts, missing docs — 8. Routes to required DOTGROUP financial authority — 9. Authorized financial officer reviews — 10. If all met, approved for execution — 11. Payment executed via configured authorized payment process — 12. Records payment reference + confirms outcome — 13. Ledger updated only according to confirmed result — 14. Requester + representatives receive notification — 15. Appears in financial statement + audit log — Important: Submitting complaint, pressing button, sending message to registered phone must never automatically count as approval — Each approval must be explicit authenticated action — Complaint different from financial approval — Interface must provide separate options: Approve Withdrawal, Reject Withdrawal, Raise Objection, Submit Financial Complaint, Request More Information
Representative Independence & Anti-Collusion + Objections
Five-to-six-person rule intended to create collective accountability — Strengthen by requiring: Separate authenticated accounts, Distinct eligible representatives, No duplicate approval from same person, No approval by account acting on behalf of multiple representatives, Conflict-of-interest declarations, Clear identification of requester, Record each approval + timestamp, Record rejected/withdrawn requests, Additional review for unusual transactions, Detection of suspicious approval patterns — Where practical, requester should not count toward required number independent approvals for own withdrawal — DOTGROUP should define authorized representative-selection process & periodically review list — Do not treat five approvals as guarantee legitimate — Keep DOTGROUP financial authorization + audit controls — Objections: When authorized objection or credible fraud concern raised: Mark On Hold, Notify DOTGROUP financial + oversight officers, Record reason + evidence, Prevent release while review pending, Allow investigation, Record decision + reason, Notify parties, Allow appeal — System must not automatically treat every complaint as proof of fraud — However credible unresolved financial concern must not be ignored merely because 5-6 approvals collected — Emergency process for freezing suspected fraudulent transaction, restricted access, mandatory documentation, timely human review
